# yeemio-ops

Public ops toolkit for [@yeemio](https://x.com/yeemio) / Yeemio | Control.

Small, real friction fixes from day-to-day work — not a product platform.

## Tools

| Dir | What it solves |
| --- | --- |
| `handoff-wake/` | Auto-wake Control when OwlCodaE PRs carry `Handoff → Yeemio \| Control` (stop missing assigned work) |
| `fde-crumbs/` | Desensitized FDE build/scenario crumbs → X·内容 draft queue (never auto-publish) |
| `first-hour-spike/` | Mid-day ping when a @yeemio original opens much faster than that day's median at ~15m |
| `ui-evidence-scaffold/` | Scripts + DELIVERED comment skeleton for “restore clean dir + normal DSH entry” packages (e.g. PR #61) |

## Rules of the road

- X: research / drafts only. Humans publish.
- OwlCodaE: FDE writes with ZCode on Control’s shared box; Control assigns & tracks; Codex merges. No CloudAgent for OwlCodaE.
- Prefer silent over filler.
