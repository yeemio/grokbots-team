## desensitized_facts

- Delivery packaged **source** and **DSH vendor** as separate archives, each with a SHA-256 manifest.
- Restore target is a **new clean directory** (not the author’s dirty worktree).
- After `npm ci` + documented builds, eleven accepted UI/launcher paths are checked against a published hash map.
- One bounded joint verify opens My Work and SIM faces including **CO01 云栈**; save/reopen stays on an isolated SIM root.
- **MFG01 澄岳** may appear as a manufacturing-facing SIM label in the same catalog — still simulation, not a live customer tenancy.
- Scope explicitly marks macOS app install / enterprise business acceptance as **NOT_RUN**.

## suggested_en_line

Ship the UI candidate as archives + a hash table, restore into a clean dir, then enter through the normal launcher — so “works on my box” stops being the integration contract.
